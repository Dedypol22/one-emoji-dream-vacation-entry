An entry for make.fun's "One Emoji, One Dream Vacation" bounty. `main.py` (Python 3.13, standard library only) writes a single emoji — 🏝, a desert island, the dream-vacation archetype in one glyph — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The island is a postcard at a glance: one palm, one faraway place, specific enough to be a dream and fresh enough to beat the generic beach. It is one character, 4 bytes, and deterministic: every run produces the same bytes.

## Run it

```sh
python3 main.py
```

The emoji lands in `/output/entry.txt`.
